# Security

Only the [latest release](https://github.com/PewPewzxc/VARAGH/releases/latest) gets fixes.

If you find a security problem (for example in the Wi-Fi file transfer or the
web server), please **do not open a public issue**. Report it privately with
GitHub's [private vulnerability reporting](https://github.com/PewPewzxc/VARAGH/security/advisories/new).
You will get an answer as soon as possible.
